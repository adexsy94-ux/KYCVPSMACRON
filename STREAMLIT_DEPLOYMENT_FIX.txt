STREAMLIT CLOUD OPENPYXL FIX — V12
==================================

The app uses pandas.read_excel() for XLSX files. Pandas requires the
openpyxl Python package for that operation.

IMPORTANT
---------
Streamlit Community Cloud auto-detects a file named exactly:
    requirements.txt

A file named requirements_v12.txt is not the standard dependency file and
may be ignored. Put requirements.txt either:
  1. in the repository root, OR
  2. in the same folder as kyc_driven_vps_macron_reconciliation_v12.py

GitHub folder should look like:
    kyc_driven_vps_macron_reconciliation_v12.py
    requirements.txt

Then commit/push both files. Streamlit should trigger a dependency rebuild.
If it does not, reboot the app from Streamlit Cloud. If the app was created
with an unwanted Python version and still has dependency issues, redeploy
and select a supported Python version in Advanced settings.

This package also adds a friendly startup check so that, if openpyxl is
missing again, the app shows the exact dependency fix instead of failing
inside pandas.read_excel().
